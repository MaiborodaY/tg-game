# Игровая графика

- [BroTD Infinity — враги, боссы и карты](brotd-infinity/README.md)

В коллекции хранятся исходники, облегчённые WebP, описания кадров и превью. Для загрузки в игру предназначены файлы `*-lite.webp` и соответствующие `*.frames.json`; исходники и превью нужны для работы с графикой.
