# Багровый граф / Crimson Count

Концепт вампира, отложенный по решению пользователя для финального босса **третьего уровня**. Финальный босс второго уровня — [Король склепа](../../../level-02/bosses/crypt-king/README.md).

Бледная кожа, багровые глаза, тёмные волосы с серебристыми висками, высокий воротник, тёмный плащ с винной подкладкой и силуэтом крыльев летучей мыши. В вытянутой руке — небольшое багровое свечение.
