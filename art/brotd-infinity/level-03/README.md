# BroTD Infinity — третий уровень

Третий уровень продолжает территорию нежити во владениях вампира: каменный двор замка, багровые огни, готические ворота и ожившие доспехи.

| Категория | Содержимое | Статус |
| --- | --- | --- |
| [Обычные враги](enemies/README.md) | Проклятый латник — ближний бой; Плачущая невеста — дальний бой | У каждого по 16 кадров; у невесты отдельный снаряд |
| [Мини-боссы](mini-bosses/README.md) | Оживший орган | 16 кадров и отдельная звуковая волна |
| [Карты](maps/README.md) | Двор Багрового замка | Утверждённый фон, два размера WebP |
| [Боссы](bosses/README.md) | Багровый граф, вампир | 16 кадров и отдельный багровый снаряд |

Для загрузки юнита берите облегчённый `*-lite.webp` и `*.frames.json`. Для карты выберите один WebP: **165202 байта** для 780 × 1080 или **60184 байта** для 390 × 540. PNG, lossless-копии, иллюстрации и превью предназначены для работы с графикой.

Комплект латника занимает **103310 байт** с JSON, комплект невесты — **158646 байт** с осколком и двумя JSON, комплект Ожившего органа — **181599 байт** с волной и двумя JSON, комплект Багрового графа — **140267 байт** со снарядом и двумя JSON. Два обычных юнита, мини-босс и финальный босс вместе с основным фоном — **749024 байта**, с компактным фоном — **644006 байт**; справочный JSON карты в эти суммы не включён.

У каждого объекта отдельная папка с описанием и полными запросами генерации. Ассеты подготовлены в ветке `codex/brotd-level-3-assets`, созданной от `main` на коммите `5135f34dcf956aceb03cf693c522fa20b1f78981`. Ветка содержит графику и документацию; игровые волны, параметры и подключение новых изображений в её состав не входят.
