# Юниты игрока

- [Эльфы](elves/README.md): наездница на пантере с глефой, лучница, боевой единорог и лекарь.

Папки сгруппированы по расам, внутри каждой расы — по юнитам. В игровых загрузках нужны облегчённые WebP и JSON кадров; исходники и превью предназначены для работы с графикой. Добавление файлов в этот каталог само по себе не подключает юнитов к игре.
