# Эльфийская всадница на пантере

Новая утверждённая версия — [наездница с метательной лунной глефой](glaive-v2/README.md). Ниже описан предыдущий вариант с саблей; его файлы сохранены по прежним путям.

Союзный юнит ближнего боя: эльфийка с серебряной косой и изогнутой саблей верхом на большой чёрной пантере. Комплект подготовлен по утверждённому концепту. Включены только графика, описание кадров и превью; игровой код и характеристики юнита не добавлялись.

## Кадры

Индексы идут слева направо, сверху вниз. Для нарезки следует использовать `rect` из JSON: границы подобраны по прозрачным промежуткам и могут отличаться от равномерной сетки 192×192.

| Индексы | Action | Последовательность |
| --- | --- | --- |
| 0–3 | `idle-right` | Ожидание: небольшое движение корпуса, головы и хвоста |
| 4–7 | `walk-right` | Шаг пантеры на месте, смена опорных лап |
| 8–11 | `attack-right` | Готовность → приседание перед выпадом → удар вправо → возврат |
| 12–15 | `attack-down` | Те же четыре фазы при взгляде в сторону нижнего края экрана |

`impactPose: 2` обозначает визуальный пик удара: кадры **10 и 14**. Подготовка к удару короткая, без высокого замаха. Всадница остаётся в седле; сабля сохраняется в одной руке. Направление `down` показано отдельными фронтальными позами.

`footAnchor` задаётся в пикселях относительно собственного прямоугольника кадра (`anchorSpace: frame-pixels`). По X это предложенная точка под седлом; по Y — линия нижней опорной лапы. Эти точки использованы в превью. Для движка, ожидающего нормализованный pivot, координаты нужно делить на ширину и высоту соответствующего `rect`.

Скорость воспроизведения, масштаб на поле, коллизии, урон и попадание по цели задаются при интеграции. Левого и заднего направлений, смерти и отдельных эффектов удара в комплекте нет. Проверки боя в игре не выполнялись, поскольку комплект не подключён к игровому коду.

## Проверка экспорта

В атласе найдены 16 отдельных силуэтов. Минимальный отступ видимого силуэта (alpha > 20) от границы своего `rect` — **27 пикселей**; максимальная alpha на самой границе — **1/255**. Прямоугольники покрывают атлас без перекрытий и пропусков. Точки опоры лежат внутри своих кадров.

После уменьшения nearest-neighbor alpha в обеих WebP совпадает с уменьшенным исходником побайтно; видимые RGB-пиксели lossless-версии также совпадают. Все изображения и четыре страницы GIF декодируются; исходные PNG сохранены побайтно. Превью проверено на отсутствие обрезанных видимых пикселей. Это проверки графических файлов, не игрового поведения.
