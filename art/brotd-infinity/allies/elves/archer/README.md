# Эльфийская лучница

Союзный юнит дальнего боя по последнему утверждённому концепту: большая голова, короткие ноги, светлый хвост, простой зелёный костюм и небольшой деревянный лук. Детализация и пропорции намеренно упрощены относительно первой иллюстрации лучницы.

Комплект содержит графику, описание кадров и превью. Юнит не подключён к игровому коду; характеристики и боевое поведение не менялись.

Минимальный комплект для загрузки — **110 917 байт / 108,3 КиБ**. Для этого варианта нужны только эти два файла. Размеры указаны до транспортного сжатия, без HTTP-заголовков.

Альтернатива для более крупного отображения: [WebP 768×768](elf-archer-768-lite.webp), 194 422 байта, и [соответствующий JSON](elf-archer-768.frames.json), 4 654 байта. Вместе — 199 076 байт / 194,4 КиБ. Загружать оба разрешения одновременно не требуется. Координаты в JSON привязаны к своему разрешению: смешивать атлас 512 с JSON 768 нельзя.

## Кадры

| Индексы | Action | Последовательность |
| --- | --- | --- |
| 0–3 | `idle-right` | Небольшие движения корпуса, хвоста и плаща; лук опущен |
| 4–7 | `walk-right` | Четыре фазы шага с чередованием коротких ног |
| 8–11 | `shoot-right` | Зарядить стрелу → натянуть тетиву → выпустить → опустить лук |
| 12–15 | `shoot-down` | Те же фазы при стрельбе к нижнему краю экрана |

`releasePose: 2` обозначает выпуск стрелы: **кадры 10 и 14**. На выпуске и восстановлении стрелы на луке уже нет. Отдельного летящего снаряда в этом атласе нет: его отображение и момент появления задаются при интеграции.

Использовать нужно явные `rect` из JSON, а не равномерную сетку. Границы проходят по прозрачным промежуткам и сохраняют весь лук, стрелу и волосы. `footAnchor` задаётся в пикселях относительно собственного кадра (`anchorSpace: frame-pixels`): это предложенная точка между ботинками на линии земли. Опущенный перед персонажем лук не входит в расчёт линии опоры. Для нормализованного pivot координаты нужно делить на ширину и высоту своего `rect`.

Масштаб, частота кадров, направления, снаряд, попадания, урон и анимация смерти задаются отдельно. Левого и заднего направлений, смерти и отдельных эффектов выстрела в комплекте нет. Проверки боя в игре не выполнялись.

## Проверка экспорта

Найдены 16 отдельных силуэтов. При alpha > 20 минимальный отступ до границы кадра составляет **6 пикселей для 768** и **4 пикселя для 512**; на самой границе alpha не выше **1/255**. Прямоугольники покрывают каждый атлас без перекрытий и пропусков, точки опоры находятся внутри своих кадров.

Alpha в обоих облегчённых WebP совпадает с соответствующим уменьшенным исходником побайтно. Lossless-версия также сохраняет видимые RGB-пиксели уменьшенного исходника. Оба исходных PNG сохранены побайтно. Изображения и четыре страницы GIF декодируются; превью проверено на отсутствие обрезанных видимых пикселей. Это проверка файлов графики, не игрового поведения.
