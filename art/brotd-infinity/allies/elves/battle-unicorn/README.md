# Боевой единорог

Бронированный союзный зверь эльфийской армии по утверждённому боевому концепту: мощная шея и грудь, суровый взгляд, стальной налобник, зелёная попона и один рог для удара. Без всадника. Компактные пропорции и простая пиксельная графика сохранены.

Комплект содержит графику, описание кадров и превью. Юнит не подключён к игровому коду; характеристики и боевое поведение не менялись.

## Кадры

| Индексы | Action | Последовательность |
| --- | --- | --- |
| 0–3 | `idle-right` | Ожидание: небольшие движения корпуса, головы и гривы |
| 4–7 | `walk-right` | Четыре фазы шага с чередованием передних и задних ног |
| 8–11 | `attack-right` | Готовность → опустить голову и перенести вес назад → короткий выпад рогом → возврат |
| 12–15 | `attack-down` | Те же фазы при ударе к нижнему краю экрана, с фронтальным ракурсом |

`impactPose: 2` обозначает визуальный пик удара: **кадры 10 и 14**. Атака показана коротким выпадом с опущенной головой. Фактическое перемещение, дистанция удара, попадание и урон задаются при интеграции; атлас не реализует механику рывка.

Для нарезки следует использовать явные `rect` из JSON, а не равномерную сетку. Прямоугольники проходят по прозрачным промежуткам и сохраняют весь рог, хвост и копыта. `footAnchor` задан в пикселях относительно собственного кадра (`anchorSpace: frame-pixels`): предложенная точка под корпусом между копытами на линии земли, использованная в превью. Для нормализованного pivot координаты делятся на ширину и высоту своего `rect`.

Скорость анимации, масштаб, коллизии, урон и способности остаются отдельной работой. Левого и заднего направлений, смерти, лечения и отдельных эффектов удара в комплекте нет. Проверки боя в игре не выполнялись.

## Проверка экспорта

Исправлено соприкосновение рога и хвоста соседних кадров первого варианта. В выбранном атласе найдены 16 отдельных силуэтов. При alpha > 20 минимальный отступ до границы кадра составляет **25 пикселей для 768** и **17 пикселей для 512**; на самой границе alpha не выше **1/255**.

Прямоугольники полностью покрывают каждый атлас без перекрытий и пропусков, точки опоры находятся внутри своих кадров. Alpha облегчённых WebP совпадает с соответствующим уменьшенным исходником побайтно; lossless-версия также сохраняет видимые RGB-пиксели. Оба исходных PNG сохранены побайтно. Все изображения и четыре страницы GIF декодируются; превью проверено на отсутствие обрезанных видимых пикселей. Это проверка графических файлов, не игрового поведения.
