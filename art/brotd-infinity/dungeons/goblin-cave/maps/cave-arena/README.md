# Пещера гоблинов — игровая карта

Пиксельный фон подземелья для боя с «Жабьим троном»: тёмная пещерная вода, скалы, факелы, красные гоблинские знамёна и широкое свободное поле. Сверху тянется подход к арене. Слева внизу сохранена небольшая площадка игрока с синим навесом и соединением с основным полем.

Для мини-аппа загружать один выбранный WebP. PNG и промпты не нужны игроку. Экспорт: WebP quality 85, nearest-neighbor. Исходные пропорции практически совпадают с целевыми; источник приведён к точному размеру без обрезки.

## Основа и расположение

18 сентября 2026 года проверены свежий `origin/main` (`d8bab9c`), текущие `field.mjs` и `tiny-map.mjs` в рабочем дереве `pixel-chronicle`, а также запущенная локальная игра. Геометрия поля в этих версиях совпадает; локальная ветка игры дополнительно содержит героя.

Обновлённая базовая область обзора — **502×445**, начиная с мирового x = −56. Основное поле имеет высоту 445, король расположен на левой площадке с узким соединением с материком. На высоком экране отрисовщик показывает дополнительный подход сверху. Старая компоновка 390×540 с королём снизу по центру не использовалась.

Новый фон покрывает мировую область **x = −56…446, y = −445…445**:

- Нижняя половина изображения соответствует базовому полю 502×445.
- Верхние 445 логических пикселей — запас подхода для высокого экрана.
- Перевод мировых координат в изображение 502×890: `imageX = worldX + 56`, `imageY = worldY + 445`. Для версии 1004×1780 результат умножается на два.
- Сетка армии: 5×3, начало (50, 270), шаг 58×55 в мировых координатах.
- Ступни короля: (−28, 410), то есть (28, 855) на компактном изображении.
- Маршрут к королю: (34, 408) → (−14, 408); проходит через нижний левый перешеек.

При последующем подключении сохранять масштаб мировых координат и привязку к нижнему краю. Нельзя сжимать всю картинку 502×890 в базовую область 502×445: это изменит расположение арены и перешейка. Для области выше y = −445 потребуется отдельное продолжение; фон не является бесшовным тайлом.

JSON — справочник композиции, не подключённая конфигурация и не карта столкновений. Контуры берегов нарисованы художественно; финальные размеры персонажей, перекрытия и границы движения проверяются при интеграции.

## Генерация и проверка

[Точные промпты](generation-prompts.md). Генерация и перенос левой площадки выполнены встроенным **imagegen**. Референсы: одобренная иллюстрация «Жабьего трона» для темы и снимок текущей игры для композиции. Первая версия перенесла проход слишком высоко; выбран исправленный вариант.

Экспорт выполнен через Sharp. Проверены размеры, непрозрачность и декодирование обоих WebP, побайтная сохранность исходного PNG. На отдельном служебном превью поверх карты сверены сетка армии, точка короля и центральная линия маршрута; разметка не входит в фон.

Это статичный художественный ассет. Игровой код, активная карта, анимации окружения и бой не изменялись; тест боя с новым фоном не проводился.
