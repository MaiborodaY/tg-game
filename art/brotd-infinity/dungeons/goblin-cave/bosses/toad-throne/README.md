# Жабий трон

Финальный босс подземелья «Пещера гоблинов»: небольшой король с золотой короной, красным плащом и скипетром сидит на троне, закреплённом на огромной бронированной жабе. Жаба, король, трон и знамёна нарисованы одним спрайтом.

Комплект содержит только графику и данные нарезки. Игровой код, волны и способности не менялись.

Боевой комплект: **162 035 байт / 158,2 КиБ**. Вместе с картинкой данжа: **220 123 байта / 215,0 КиБ**, до транспортного сжатия и HTTP-заголовков.

Для крупного изображения босса предусмотрены [атлас 768×1152](toad-throne-768-lite.webp), 293 414 байт, и [JSON 768](toad-throne-768.frames.json), 6 686 байт: вместе **300 100 байт / 293,1 КиБ**. Вариант [картинки данжа 768×768](goblin-cave-cover-768.webp) весит 98 636 байт / 96,3 КиБ. При интеграции выбрать одно разрешение каждого изображения; загружать оба не требуется. JSON использовать с атласом того же разрешения.

## Анимации

| Кадры | Action | Фазы слева направо |
| --- | --- | --- |
| 0–3 | `idle-right` | Ожидание, дыхание, моргание |
| 4–7 | `walk-right` | Четыре фазы тяжёлого шага |
| 8–11 | `bite-right` | Готовность → раскрыть пасть → сомкнуть челюсти → восстановиться |
| 12–15 | `bite-down` | Те же фазы укуса в ракурсе к нижнему краю экрана |
| 16–19 | `leap-right` | Присесть → взлететь → тяжело приземлиться → восстановиться |
| 20–23 | `leap-down` | Те же фазы прыжка в ракурсе к нижнему краю экрана |

`impactPose: 2` — визуальная фаза укуса или приземления; `impactFrames: [10, 14, 18, 22]`. Это графические отметки. Дальность, перемещение, урон, время предупреждения и область поражения задаются при интеграции.

Нарезать по явным `rect` из JSON: они проходят по прозрачным промежуткам, а не по равномерной сетке. `footAnchor` задан относительно собственного кадра в пикселях (`anchorSpace: frame-pixels`). Это точка на земле под корпусом жабы. В воздушных кадрах 17 и 21 опора остаётся на земле, чтобы прыжок сохранял высоту; нельзя автоматически переносить её к поднятым лапам. Нормализованный pivot получается делением координат на размеры своего `rect`.

Левого и заднего ракурсов, анимации смерти и отдельных эффектов удара в комплекте нет. Игровое поведение не тестировалось.

## Проверка файлов

В исходном атласе найдены 24 отдельных силуэта. Минимальный отступ видимых пикселей (alpha > 20) до границы кадра: 4 пикселя в версии 768 и 3 пикселя в версии 512; alpha на границах не выше 2/255.

Прямоугольники покрывают каждый атлас без перекрытий и пропусков. Все точки опоры находятся в своих кадрах. Alpha облегчённых WebP совпадает с соответствующим уменьшенным исходником побайтно; lossless сохраняет также видимые RGB-пиксели. Оба исходных PNG сохранены без изменений. Проверены декодирование файлов, все страницы GIF и отсутствие обрезанных видимых пикселей в превью.
