# BroTD Infinity — второй уровень

[Вся коллекция BroTD Infinity](../README.md)

## Где искать

| Категория | Папка | Содержимое |
| --- | --- | --- |
| Обычные враги | [enemies](enemies/README.md) | Мечник-скелет, лучник-скелет, гуль |
| Мини-боссы | [mini-bosses](mini-bosses/README.md) | Склепный паук |
| Финальные боссы | [bosses](bosses/README.md) | Король склепа |
| Карты | [maps](maps/README.md) | Забытое кладбище: территория нежити |
| Ранние концепты | [concepts](concepts/) | Лучник, гуль и отклонённый скелет с топором |

У каждого юнита отдельная папка с исходником PNG, облегчённым WebP, JSON с координатами кадров, превью и описанием генерации. Концепты паука и Короля склепа находятся непосредственно в их папках.

Для игры берите `*-lite.webp` и соответствующий `*.frames.json`. PNG, lossless WebP и превью не нужны для загрузки игроку. Используйте явные прямоугольники из JSON: у прежних юнитов некоторые позы выходят за условную равномерную сетку. Три облегчённых атласа обычных врагов суммарно занимают **476024 байта**.

Все пять облегчённых атласов второго уровня — три обычных врага, паук и Король склепа — занимают **809130 байт** без JSON. Атлас Короля склепа отдельно — **127576 байт**, 16 кадров ожидания, ходьбы и ударов колоколом.

Для [карты кладбища](maps/forgotten-graveyard/README.md) подготовлены непрозрачные WebP 780 × 1080 (159242 байта) и 390 × 540 (59486 байт). Загружать нужно один выбранный вариант. Справочные координаты поля находятся в `forgotten-graveyard.layout.json`.

Финальный босс второго уровня — [Король склепа](bosses/crypt-king/README.md). Концепт вампира [Багрового графа](../level-03/bosses/crimson-count/README.md) сохранён для третьего уровня. Скелет с топором в `concepts/` — отклонённый вариант, а не четвёртый обычный враг.

## Перенос прежних ассетов

В ветке `codex/brotd-crypt-spider-assets`, созданной от `main` (`864b83a66bd90be2015dc72c58930d1d86d23b4d`), папки `skeleton-footman`, `skeleton-archer` и `ghoul` перенесены на один уровень глубже, в `enemies/`. Изображения и JSON сохранены побайтово; относительные ссылки документации обновлены.

Перед переносом проверены отслеживаемые файлы репозитория и локальный прототип BroTD (`king-defense-toon`). Прямых загрузок из этих исходных папок не обнаружено. Прототип загружает отдельные копии `assets/web/skeleton-footman.webp`, `assets/web/skeleton-archer.webp` и `assets/web/ghoul.webp`; эти файлы и код игры перенос не меняет. Старый шаблон пути в документации прототипа теперь соответствует `art/brotd-infinity/level-02/enemies/<name>/<name>-768-lite.webp`.

Эта ветка содержит только графику и документацию. Подключение паука и Короля склепа к игровым волнам, их параметры и способности сюда не входят.
