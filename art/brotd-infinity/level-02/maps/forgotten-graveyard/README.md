# Забытое кладбище / Forgotten Graveyard

**Дизайн утверждён. Статичный ассет готов:** основной [WebP 780 × 1080, 159242 байта](forgotten-graveyard-780x1080-lite.webp) и компактный [WebP 390 × 540, 59486 байт](forgotten-graveyard-390x540-lite.webp). Размеры, декодирование и непрозрачность повторно проверены после утверждения. В игру загружается один выбранный вариант.

Карта второго уровня на территории нежити, версия 1. Сухая серо-коричневая земля, мёртвые деревья, перекошенные надгробия и ограды, паутина, тёмная болотная вода. Вместо синего замка в нижнем левом углу — старый склеп с фиолетовыми огнями. Основная площадка остаётся светлее окружения, чтобы на ней читались скелеты, гуль, паук и союзные бойцы.

Создана встроенным `imagegen` по [снимку реально используемой карты](reference/current-map-390x540.png). [Полный запрос генерации](generation-prompt.md) сохранён рядом.

## Геометрия

Взята из существующих `tiny-map.mjs` и `field.mjs` прототипа `king-defense-toon`:

- Логическое поле: **390 × 540**.
- Вход противников: сверху, по центру; проход расширяется к арене.
- Расстановка: **5 × 3** клетки, начало **(50, 270)**, шаг **58 × 55**, прямоугольник **290 × 165**.
- Король: **x = 195**, линия ступней **y = 493**.
- Центральный тыловой проход сохранён; склеп размещён сбоку, в нижнем левом углу.

Размещайте изображение целиком в пределах логического поля, без `cover`-обрезки. JSON — справочник по композиции, не карта столкновений и не подключённая конфигурация движка. Перед подключением нужно проверить наложение живых юнитов и интерфейса на обеих сценах.

## Текущий статус

Подготовлен статичный фон. Действующая карта собирается из отдельных тайлов и декораций, с анимацией деревьев и бликов воды; этот файл не является заменой её тайлсета. Автоматического переключения уровня и изменений игрового кода в этой ветке нет. PNG референса получен вызовом существующего `createTinyMap().draw(context, 0)` без изменения отрисовщика. Неиспользуемая старая иллюстрация `battlefield-toon.png` не бралась за основу.

Исходные тайлы референса: Tiny Swords (Update 010), Pixel Frog, из предоставленного локального набора проекта. [Страница автора](https://pixelfrog-assets.itch.io/tiny-swords).

## Проверка

Просмотрены сгенерированный фон, уменьшение 390 × 540 и основной WebP 780 × 1080. Файлы декодируются, пропорции и непрозрачность проверены. Проверены ссылки каталога. Это проверка графических файлов, без запуска боя на новом фоне.
