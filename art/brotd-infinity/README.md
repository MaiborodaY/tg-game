# BroTD Infinity — коллекция ассетов

## Подземелья

- [Пещера гоблинов](dungeons/goblin-cave/README.md): «Жабий трон», боевые анимации босса, иллюстрация данжа и карта пещерной арены.
- [Каталог подземелий](dungeons/README.md).

## Юниты игрока

- [Союзные расы](allies/README.md): графика юнитов игрока.
- [Эльфы](allies/elves/README.md): наездница на большой чёрной пантере с глефой, лучница, боевой единорог и лекарь.

## Первый уровень

- [Каталог первого уровня](level-01/README.md): гоблины, кабан, лекарь, вождь и огр; ссылки на прежнюю игровую графику.
- [Мини-боссы](level-01/mini-bosses/README.md): вождь гоблинов и новый Гоблин-бомбардир на пушке.

## Второй уровень

- [Обычные враги](level-02/enemies/README.md): мечник-скелет, лучник-скелет, гуль, Чумной алхимик с ядовитыми бутылками.
- [Мини-боссы](level-02/mini-bosses/README.md): склепный паук.
- [Финальные боссы](level-02/bosses/README.md): Король склепа.
- [Карты](level-02/maps/README.md): Забытое кладбище, территория нежити.
- [Каталог второго уровня](level-02/README.md): форматы, размеры файлов и сведения о переносе.
- [Ранние концепты](level-02/concepts/): включая отклонённого скелета с топором.

Каждый враг хранится в отдельной папке. В ней находятся прозрачный WebP, JSON с кадрами, исходник PNG, превью и описание. Концепты мини-боссов и боссов хранятся рядом с их анимациями. Карты хранятся в `maps/`, отдельно от юнитов, с облегчёнными WebP и схемой размеров.
