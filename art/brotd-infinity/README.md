# BroTD Infinity — коллекция ассетов

## Второй уровень

- [Обычные враги](level-02/enemies/README.md): мечник-скелет, лучник-скелет, гуль.
- [Мини-боссы](level-02/mini-bosses/README.md): склепный паук.
- [Каталог второго уровня](level-02/README.md): форматы, размеры файлов и сведения о переносе.
- [Ранние концепты](level-02/concepts/): включая отклонённого скелета с топором.

Каждый враг хранится в отдельной папке. В ней находятся прозрачный WebP, JSON с кадрами, исходник PNG, превью и описание. Концепт нового мини-босса хранится рядом с его анимациями. Финальный босс второго уровня ещё не подготовлен.
