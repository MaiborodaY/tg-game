# Дворовый Бридж

Telegram Mini App с народным вариантом Бриджа на сброс карт. Это не контрактный спортивный бридж.

## Правила этой версии

- Играют вдвоём колодой из 36 карт: от шестёрки до туза.
- Каждый получает пять карт; пятая карта сдающего открывает стол, поэтому у сдающего остаётся четыре и он ходит первым.
- Ходят картой той же масти или того же достоинства. За один ход можно сбросить несколько карт одного достоинства.
- Если подходящей карты нет, игрок берёт одну карту и передаёт ход.
- Положивший 6 обязан накрыть её сам; если подходящей карты нет, он добирает до первой подходящей. Туз пропускает ход соперника; 7 даёт сопернику одну карту; 8 даёт две карты и пропускает его ход; валет кладётся на любую карту и заказывает масть.
- Проигравший раунд получает штраф за оставшиеся карты: 6–9 дают 0, 10/Q/K — по 10, A — 15. Валеты дают по 20, только если в руке остались одни валеты; вместе с картами других достоинств каждый J даёт 10.
- Завершение валетом удваивает штраф раунда. Четыре подряд карты одного достоинства немедленно завершают раунд и тоже дают множитель ×2; бонусы не перемножаются.
- Ровно 125 штрафных очков сбрасываются до 0. Игрок проигрывает матч, только когда набирает больше 125; победителем становится его соперник.

## Режимы

- Solo: игрок `south`, соперник `west` управляется ИИ.
- PvP: два человека занимают `south` и `west`, подключаясь по шестизначному коду комнаты.

Telegram-аутентификация, WebSocket-комнаты, восстановление соединения и таймеры хода обслуживаются Worker `bridge-pvp`.

Интерфейс доступен на русском, украинском и английском. Язык выбирается по сохранённой настройке, языку Telegram или браузера; его можно переключить вручную.

## Локальный запуск

Клиент и одиночная игра:

```powershell
npm.cmd run bridge:dev
```

Клиент вместе с локальным PvP Worker:

```powershell
npm.cmd run bridge:pvp:dev
```

Для проверки комнаты откройте две вкладки с разными параметрами `dev_user`, например:

- `http://127.0.0.1:8787/?dev_user=alice`
- `http://127.0.0.1:8787/?dev_user=bob`

## Проверки

```powershell
npm.cmd run bridge:test
npm.cmd run bridge:typecheck
npm.cmd run bridge:build
npm.cmd run bridge:pvp:test
npm.cmd run bridge:pvp:typecheck
```
